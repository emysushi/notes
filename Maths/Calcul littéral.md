
# Fractions 

- addition : a/b + c/b = a+c/b
-  soustraction  : a/b - c/b = a-c/b
- multiplication : a/b * c/d = ac/bd
- division : a/b / c/d = a/b * d/c
# Distribuitivité 

- a(b+c) = ab + ac
- (a+b)(c+d) = ac + ad + bc +bd

# Indentités remarquables 

-  (a+b) ² = a ² + 2ab + b ²
- (a-b) ²  = a ² - 2ab + b ²
- (a + b)(a - b) = a ² - b ²
