
# symboles

-  ∀ : quelque soit
- ∃ : il existe
- ∈ : appartient
- ∉ : n'appartient pas
- ⊆ : est inclu dans
# les nombres entiers 

- entiers naturel :
	- nombres entiers positifs (+)
	- notation ℕ
- entiers relatifs :
	- nombres entiers positifs ou négatif (+ ou -)
	- notation ℤ

# les nombres rationnels

- nombre qui s'écrit sous la forme a/b ou a et b sont des entiers relatifs (+ ou -)

- ensembles rationnels :
	-  ne peuvent pas s'écrire sous la forme d'une fraction
	- notation ℚ
- ensembles décimaux :
	-  peuvent s'écrire sous la forme 10na où a et n sont des entiers relatifs (+ ou -)
	- notation ⅅ
- nombre réel :
	- s'écrit avec une partie entière et décimale, éventuellement infinie
	- notation ℝ


| ℕ                 | ℤ                  | ⅅ                   | ℚ                     | ℝ           |
| ----------------- | ------------------ | ------------------- | --------------------- | ----------- |
| entiers naturel < | entiers relatifs < | ensemble décimaux < | ensemble rationnels < | nombre réel |
